// 01 · Overview

プロジェクト概要

ゲーム開発における頂点アニメーションテクスチャ（VAT）を GPU 計算で生成・管理するシステム。 高周波のオーディオ入力をリアルタイムで HSV カラー空間に変換し、シェーダーで実装することで、 複雑なメッシュアニメーションと音声ビジュアライゼーションを融合させたポートフォリオ作品。

🎨

// 03 · Key Features

主要機能

Real-time Vertex Computation
DirectX12 Compute Shader で頂点ポジション・法線・カラーをリアルタイム計算。 GPU メモリバンド幅を最大活用し、大規模メッシュも高速処理。
Audio-driven HSV Coloring
FFT 解析したオーディオスペクトラムを HSV 色空間に変換。 時間軸で Hue をシフト、振幅で Saturation・Value を制御し、サイケデリックな映像表現を実現。
VAT Export Pipeline
生成した頂点アニメーションテクスチャ（VAT）を標準形式で書き出し。 Unity・Unreal Engine でシェーダーサポートがあれば即座に再利用可能。
Performance Profiling
DirectX12 GPU タイマークエリで各ステージのミリ秒単位の計測。 ボトルネック分析で最適化の指針を提供。
